The platform

These repositories show my expertise across every field of an end-to-end platform.

Method

Infrastructure is code, and code gets reviewed

Nothing changes by hand. Every environment comes out of a Terraform root or a Helm chart, goes through a plan someone reads, and is applied by a pipeline, not a laptop.

Validate like production

QA practices apply to all of my work, not only to application code. terraform fmt, validate and tflint per root; helm lint --strict plus kubeconform against the real CRD catalog; hadolint, shellcheck, pytest, ruff. The same gates in CI on every repository.

Build it right, in every language

I own the build pipelines for my own code and for the developers': Java with Maven and Gradle, Python, Angular, Node and npm, Lua. Pinned toolchains, cached dependencies, unit tests and linters as gates, and every artifact or image versioned and traceable to a commit.

Deploy through pipelines, and tell people

Deployments are pipelines with environments, approvals and a rollback path: Helm releases, Terraform applies, VM playbooks. Every run reports to Slack or Teams with what changed, where and by whom. Failures notify the channel that can act, not everyone.

Observability as a method

Prometheus and Alertmanager for metrics and alerting, with tuned rule sets and one shared alert card. Grafana for the questions people actually ask. ELK for logs, with lifecycle policies that fit the budget. Every alert has an owner, a runbook and a reason to exist. Anything that fires without action gets tuned or removed.

Document everything, decisions included

Every repository is documented in place, and the platform end to end in Confluence: architecture and network diagrams in draw.io, runbooks, onboarding guides and operating procedures. Architecture decision records capture why the non-obvious parts look the way they do, including the incidents that shaped them. The code says what. The docs say why.

FinOps is part of the job

Cost is a design input, not an afterthought. Non-production environments shut down on a schedule, budgets alert to Slack before the invoice does, right-sizing comes from real Azure Monitor data, and cost per tenant is a query anyone can run. Reserved capacity where the load is predictable, autoscaling where it is not.

Code, not only configuration

I write software on my own, in Python, Go and Lua: platform tooling, automation and integrations, and personal projects published on GitHub. Tested, linted and shipped through the same pipelines as everything else.
